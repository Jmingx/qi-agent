# 新手向核心循环：20 秒稿件

场景：用户要求总结 notes.txt；文件内容与回答均为教学示例，未实际调用模型。

| 时间 | 教学重点 | 动画 |
| --- | --- | --- |
| 0–2s | 一条问题进入消息历史，turn-start 通知日志 | 问题打字出现，事件光点流向插件 |
| 2–5s | pre-step 插件补充和裁剪信息 | 准备节点点亮，waterfall 说明出现 |
| 5–8s | pre-llm/post-llm 记录请求与响应 | 模型节点点亮，显示 read_file 请求 |
| 8–11s | tool-call 安全判档 | 插件显示放行；注明需要时另走 tool-approval |
| 11–14s | 工具执行、tool-result、结果回填 | 文件内容逐条出现，结果节点点亮 |
| 14–17s | 带着工具结果进入下一次循环 | 光点沿回边返回 pre-step，再到模型 |
| 17–20s | 模型不再请求工具，final-answer 输出答案 | 无工具分支通向答案，展示示例总结 |

核心区别：模型提出工具请求，执行器实际运行工具；EventBus 在事件点同步按序调用监听器。主循环仍负责状态推进、模型调用和消息回填。
