## 1. 目标

为 qi-agent 增加**可开关的调试日志**，展示 LLM 交互的完整链路：
- 发送给模型的**完整请求**（全部消息历史 + 工具定义）
- 模型返回的**完整响应**（文本或工具调用）
- 工具执行的**入参和结果**

**核心约束（用户要求）：日志逻辑必须独立，不能影响学习 agent 源码。**

## 2. 设计原理（导师讲解：关注点分离）

### 2.1 问题：日志逻辑不该和业务逻辑纠缠

在 agent.py/llm.py 里到处写 print 是最差方案——源码被日志淹没，无法学习。**日志是"横切关注点"（cross-cutting concern），应该与业务逻辑分离。**

### 2.2 两个核心机制（Java 对照）

**① 代理模式（Proxy Pattern）—— 包装 LLMClient**

```python
# Java 类比：动态代理 / 装饰器模式，不改原类拦截调用
class LoggedClient:
    def __init__(self, inner: LLMClient):
        self.inner = inner

    def chat(self, messages, tools=None):
        logger.log_request(messages, tools)            # 请求日志（拦截点）
        result = self.inner.chat(messages, tools)      # 转发真实调用
        logger.log_response(result)                    # 响应日志（拦截点）
        return result
```

- LLMClient 作为"内部组件"被包装，**llm.py 零改动**
- 日志逻辑全部在代理类里，源码保持纯净

**② 依赖注入（Dependency Injection）—— Agent 可选 logger**

```python
# Java 类比：SLF4J——logger 注入，业务代码只调 logger.xxx
class Agent:
    def __init__(self, client, system_prompt=..., max_turns=8,
                 logger: DebugLogger | None = None):   # 可选注入
        self.logger = logger

    def chat(self, user_input):
        if self.logger:
            self.logger.log_user_input(user_input)     # 一行可选调用
        ...
        result = self.client.chat(...)
        if self.logger:
            self.logger.log_response(result)           # 一行可选调用
```

- agent.py 每处只加 1 行 `if self.logger: ...`，核心逻辑零改动
- 不传 logger = 行为与现在完全一致（向后兼容）

### 2.3 开关设计：--debug 参数（默认关闭）

```bash
uv run python -m qi_agent.cli            # 正常模式，无日志
uv run python -m qi_agent.cli --debug    # 调试模式，打印完整交互
```

- 默认关闭：不影响正常使用
- CLI 解析用标准库 argparse（不引入新依赖）

## 4. DebugLogger 设计

```python
"""调试日志器：打印 LLM 交互全链路（独立模块，不依赖 agent 核心逻辑）。"""

class DebugLogger:
    """格式化输出请求/响应/工具调用的完整信息。"""

    def __init__(self, enabled: bool = True) -> None:
        self.enabled = enabled

    def log_user_input(self, text: str) -> None: ...
    def log_request(self, messages: list[dict], tools: list[dict] | None) -> None:
        """打印发送给模型的完整请求：全部消息历史 + 工具定义。"""
    def log_response(self, result) -> None:
        """打印模型响应：文本内容或 tool_calls。"""
    def log_tool_call(self, name: str, arguments: dict, output: str) -> None:
        """打印工具执行：入参 + 返回结果。"""
    def log_final_answer(self, text: str) -> None: ...
```

**输出格式（带分隔线和角色标识，一眼看懂链路）：**

```
┌─[USER] 用户输入───────────────────────────────┐
│ 现在几点了？                                   │
└────────────────────────────────────────────────┘
┌─[REQ] 发送给模型（messages + tools）───────────┐
│ messages: [{"role": "system", ...}, ...]       │
│ tools: [{"type": "function", ...}]             │
└────────────────────────────────────────────────┘
┌─[RESP] 模型响应────────────────────────────────┐
│ tool_calls: [{"name": "get_time", "args": {}}] │
└────────────────────────────────────────────────┘
┌─[TOOL] 执行工具────────────────────────────────┐
│ get_time({})                                   │
│ → 2026-08-14 22:30:00                          │
└────────────────────────────────────────────────┘
┌─[REQ] 发送给模型（第二轮）─────────────────────┐
│ messages: [...含 tool 结果回填...]              │
└────────────────────────────────────────────────┘
┌─[RESP] 模型响应────────────────────────────────┐
│ content: 现在是晚上 9 点半。                    │
└────────────────────────────────────────────────┘
┌─[ANSWER] 最终答案──────────────────────────────┐
│ 现在是晚上 9 点半。                             │
└────────────────────────────────────────────────┘
```

**关键设计：**
- 消息内容过长时截断（单条 500 字符），避免刷屏
- JSON 用 `json.dumps(ensure_ascii=False, indent=2)` 保证中文可读
- `enabled=False` 时所有方法直接 return（零开销）

## 5. Agent 集成（依赖注入）

```python
class Agent:
    def __init__(self, client, system_prompt=DEFAULT_SYSTEM_PROMPT,
                 max_turns: int = 8, logger: DebugLogger | None = None):
        self.logger = logger
        ...

    def chat(self, user_input: str) -> str:
        if self.logger:
            self.logger.log_user_input(user_input)
        self.messages.append({"role": "user", "content": user_input})

        for _ in range(self.max_turns):
            result = self.client.chat(self.messages, tools=get_tool_schemas())
            if self.logger:
                self.logger.log_request(self.messages, get_tool_schemas())
                self.logger.log_response(result)

            if result.tool_calls:
                self.messages.append(result.assistant_message)
                for call in result.tool_calls:
                    output = execute_tool(call.name, call.arguments)
                    if self.logger:
                        self.logger.log_tool_call(call.name, call.arguments, output)
                    self.messages.append({"role": "tool", "tool_call_id": call.id, "content": output})
            else:
                self.messages.append(result.assistant_message)
                if self.logger:
                    self.logger.log_final_answer(result.content or "")
                return result.content or ""

        return "已达最大轮数，任务可能未完成。"
```

**注意：日志调用全部是 `if self.logger:` 包裹的可选分支——logger 为 None 时行为和现在完全一致。**
