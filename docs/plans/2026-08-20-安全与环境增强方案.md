## 2. 设计原理（导师讲解）

### 2.1 A：路径规则为什么放 security_guard 插件（而不是 shell.py 内置）

- **架构方向**（档位 B 服务化）：工具管执行、插件管决策——安全决策集中到插件层，将来 write_file 等新工具自动获得防护
- **与黑名单的关系**：两层规则共存，任一命中即拦
  ```
  黑名单（用户配置，plugins.toml）── 管"关键词"：git push、mkfs...
  路径规则（内置，硬编码底线）──── 管"敏感路径"：type .git\config、type .env...
  ```
- **安全底线硬编码哲学**（path_security 讨论时确立）：路径规则内置且**始终生效**，不提供关闭开关（与黑名单"用户可配置"互补）

### 2.2 A：路径提取（command 字符串 → 路径 token）

```
模型传: type .git\config
  → 去引号 + 按空格拆分 → ["type", ".git\config"]
  → 逐个 token 过 is_sensitive_path():
      "type"        → abspath 后不敏感 → 放行
      ".git\config" → abspath 后含 .git 目录段 → 拦截 ✅
  → "[安全拦截] shell 命令包含敏感路径: '.git\config'，已拒绝执行"
```

- `is_sensitive_path` 复用 path_security（三段检查 + 规范化防 `..` 绕过）
- 引号处理：`replace('"', '')` 后拆分（Windows cmd 风格，够用）
- **误伤可接受**：`echo hello .git` 会被拦（token `.git` 命中敏感目录）——安全优先

### 2.3 B：env_info 是"上下文注入"插件，不是"监听事件"插件

环境信息是**静态上下文**（模型一开始就该知道），不是事件通知。用 pre-step 的 **waterfall** 模式注入：

```
第一次 step:  messages = [system, user, ...]
    ↓ env_info 注入（幂等检查）
messages = [system, [环境信息]system, user, ...]
    ↓
模型从第一轮就知道: Windows / cmd.exe / 可用命令: dir,type,echo,where...
    ↓ 效果
不再尝试 pwd/ls/cat/which → 省 2-4 轮 API 调用
```

**幂等是关键**：pre-step 每轮 step 都触发，注入必须只发生一次
（marker 前缀检查：已存在 `[环境信息]` 消息则跳过）。

## 3. 设计

### 3.1 security_guard.py 扩展（+40 行）

```python
from qi_agent.tools.path_security import is_sensitive_path

class SecurityGuardPlugin:
    def __init__(self, config=None):
        self.blacklist: dict[str, list[str]] = config.get("blacklist", {})

    def _on_tool_call(self, name, arguments, **_):
        # ① 用户配置黑名单（关键词）
        hit = self._check_blacklist(name, arguments)
        if hit:
            return hit
        # ② 内置路径规则（安全底线，始终生效）
        hit = self._check_sensitive_path(name, arguments)
        if hit:
            return hit
        return None

    def _check_sensitive_path(self, name, arguments):
        """shell 命令中的路径 token 命中敏感路径 → 拦截（修复 .git 绕过漏洞）。"""
        if name != "shell":
            return None
        cmd = str(arguments.get("command", ""))
        tokens = cmd.replace('"', "").split()
        for token in tokens:
            if is_sensitive_path(token):
                return (
                    f"[安全拦截] shell 命令包含敏感路径: '{token}'，"
                    f"已拒绝执行"
                )
        return None
```

### 3.2 env_info 插件（新文件 qi_agent/plugins/env_info.py，~60 行）

```python
"""环境信息插件：向模型注入运行环境上下文（pre-step 幂等注入）。"""

import platform

from qi_agent.events import EventBus
from qi_agent.plugins.registry import register_plugin


class EnvInfoPlugin:
    """注入运行环境信息：模型少踩环境坑（Windows 命令 vs Linux 命令）。"""

    def __init__(self, config: dict | None = None) -> None:
        self._info = self._detect()   # 构造时检测一次（静态信息）

    def _detect(self) -> str:
        """运行时检测环境，生成注入文本。"""
        system = platform.system()
        lines = [f"[环境信息] 运行环境: {system} {platform.release()}"]
        if system == "Windows":
            lines.append("shell: cmd.exe（Windows 命令），非 bash")
            lines.append("可用只读命令: dir, type, echo, where, whoami, date, time")
            lines.append("路径风格: Windows（C:\\...），目录分隔符为 \\")
        else:
            lines.append("shell: bash")
            lines.append("可用只读命令: pwd, ls, cat, echo, which, whoami, date")
        return "\n".join(lines)

    def install(self, bus: EventBus) -> None:
        bus.on("agent/pre-step", self._inject)   # 注入类：默认 priority=0

    def _inject(self, messages: list[dict], **_):
        """幂等注入：marker 已存在则跳过（pre-step 每 step 都触发）。"""
        marker = "[环境信息]"
        if any(m.get("content", "").startswith(marker) for m in messages):
            return messages
        return [{"role": "system", "content": self._info}] + messages


# 自注册：环境信息对模型有益且零风险 → 默认开
register_plugin(
    name="env_info",
    factory=EnvInfoPlugin,
    description="注入运行环境信息（OS/shell/可用命令），模型少踩环境坑",
    default_enabled=True,
)
```

## 8. 风险与说明

- **路径误伤**：任何含敏感目录段 token 的命令都被拦（`echo hello .git` 也拦）——安全优先，文档注明
- **token 化局限**：`replace('"', '')` + split 不处理转义/环境变量展开（`%USERPROFILE%`）——安全优先（拦多不拦少），复杂解析留后续
- **env_info 静态性**：环境信息构造时检测一次（会话中不变，合理）；clear_context 后幂等重注入
- **不做的**：环境探测 git 完整路径（YAGNI，模型可用 where 自查）；插件间共享环境信息（无通信机制，后续档位 B）
