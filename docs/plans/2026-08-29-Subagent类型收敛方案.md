## 一、现状问题（代码自证冗余）

```
SubagentContext（subagent.py:32）= AgentContext + 2 个字段
  （write_paths 授权清单 / timeout 超时）+ context_text 背景 + begin_chat
  → 本质是 AgentContext 的"子配置"——不是独立类型！
  → drain_messages/drain_steer 已上移（注释自己说"继承即可"）
  → 只剩配置差异（write_paths/timeout/context_text）

SubagentManager（subagent.py:71）= AgentManager 的【空壳子类】
  → 注释自己写："向后兼容别名"、"全部继承自 AgentManager"
  → 没有任何自己的方法——纯别名（历史遗留）

循环导入隐患：
  agent_manager 不模块级 import SubagentContext（subagent.py 又 import
  agent_manager → 循环）——用延迟 import 规避（agent_manager.py:28-29）
  → 删掉 SubagentContext 后循环导入【消失】（彻底简化）

## 二、目标设计（用户拍板：统一一个 Manager + 一个 Context）

```
AgentManager（唯一管理器——主/子全在这管理）：
  register(context)  # 任何 agent（主/子）——dict + 邮局 + 事件
  spawn(goal, ...)   # 建 AgentContext + 设子配置 + register（不再建子类）

AgentContext（唯一数据载体——主/子同一类型）：
  通用字段：goal / parent / max_turns / persist / events / mailbox
  子专属字段（【归拢放一块 + 注释】——用户要求）：
    # ── 子 agent 专属（spawn 时设置；主 agent 不用——默认值空）──
    self.write_paths: list[str] = []   # 授权清单（子只写这些前缀路径）
    self.timeout: float = 120.0        # 子任务超时（超时 → FAILED）
  → 主 agent 创建时这些是默认值（不用）；spawn 时设置

context_text 消除（用户确认 2026-08-29）：
  context_text 是【中间产物】（父提炼背景 → 注入子 system prompt 的原料）
  → 不占字段——spawn 时直接算成 system_prompt：
      ctx.system_prompt = _SUBAGENT_PROMPT.format(goal=goal, context=context)
  → AgentContext 已有 system_prompt 字段（本来背景就落这里）
  → delegate_task 读 ctx.system_prompt（不再 session.context_text）
```

## 三、改动清单

```
① context.py：AgentContext 加子专属字段（归拢 + 注释）
   # ── 子 agent 专属配置（spawn 设置；主 agent 默认空）──
   self.write_paths: list[str] = []   # 授权清单
   self.timeout: float = 120.0        # 子任务超时

② subagent.py：删除 SubagentContext/SubagentManager（整个文件删）
   → 引用点改后无残留

③ agent_manager.py：spawn 改建 AgentContext + 设子字段 + system_prompt
   ctx = AgentContext(context_id=session_id, goal=goal, parent=...)
   ctx.write_paths = write_paths or []    # 子专属（归拢字段）
   ctx.timeout = timeout
   ctx.system_prompt = _SUBAGENT_PROMPT.format(goal=goal, context=context)
   ctx.begin_chat()  # spawn 即运行
   self.register(ctx, role="subagent")
   → 删延迟 import（循环导入消失）

④ agents/__init__.py：删 SubagentContext/SubagentManager 导出

⑤ 测试适配：
   test_mailbox.py / test_subagent_phase3/4.py：SubagentContext → AgentContext

⑥ delegate_task.py：_ContextAdapter 保留（同步模式适配器——独立）
   —— 读 system_prompt（不再 session.context_text）
```

## 五、工业级落地考量（P0-9）

```
可靠性：
  - 统一类型（AgentContext）→ spawn/register 路径一致（无两套分支）
  - 循环导入消失（模块依赖简化——编译/加载更稳）
  - 子配置默认值安全（主 agent 不用时是空/默认——无副作用）

安全：
  - write_paths 授权清单保留（子只写白名单——安全边界不变）
  - 归拢 + 注释明确"子专属"——防止主 agent 误用子配置

记忆：
  - 无影响（会话持久化走 context——类型统一后更一致）

可观测：
  - 无影响（事件/状态机不变——register 统一上报）
```

## 六、验收标准

3. 主 agent 创建 AgentContext（子字段默认值——不用）
4. 循环导入消失（agent_manager 无延迟 import）

```
