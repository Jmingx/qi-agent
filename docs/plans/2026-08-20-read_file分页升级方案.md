## 1. 问题

```python
# read_file.py 现状：固定 2000 字符截断，无分段参数
content = f.read()
return content if len(content) <= 2000 else content[:2000] + "\n...[内容过长已截断]"
```

snake.py 207 行被截断 → 模型看不到完整代码逻辑 → 无法运行/分析。

## 2. 设计（对齐 Hermes 参考实现：75 行/offset 分段读）

### 2.1 接口升级：offset/limit 行级分页

```python
def read_file(path: str, offset: int = 1, limit: int = 2000) -> str:
    """读取文本文件指定行范围。

    Args:
        path: 文件路径
        offset: 起始行（1 起）
        limit: 最大读取行数（上限 2000——用户需求"能读取2000行"）
    """
```

### 2.2 返回格式：带元信息 header（模型可行动）

```
第 1-200 行（共 207 行）
<内容...>
...已截断（剩余 7 行），可用 offset=201 继续读取
```

- **header**：当前范围 + 总行数（模型知道文件多大）
- **tail**：剩余行数 + 续读提示（模型知道怎么继续——可行动信息设计）
- 读完（end == total）不显示 tail

### 2.3 字符上限保护（双保险）

行数上限 2000 仍可能超大（2000 行 × 100 字符 = 200KB 撑爆上下文）——
单次返回**字符上限 50_000**（截断提示含续读方法）：
```
...内容过长已截断（可减小 limit 或增大 offset 分段读取）
```
