## 1. 问题清单

### 问题 1（UI）：宽终端下右对齐留白巨大
- 日志框固定 66 列，终端 ~170 列时留白 ~100 列，日志被甩到屏幕最右，与左侧输出脱节
- **修复 A：放弃右对齐，改回左对齐 + `[LOG]` 前缀标记**

### 问题 2（真 bug）：日志内容 ≠ 实际输出（流式双调用）
- agent 最终回答轮次：① chat() 拿响应 A 记日志 → ② chat_stream() 重新生成响应 B 输出
- 模型非确定性 → A ≠ B → 日志骗人，学习工具失效
- **修复 C：最终回答轮次只调 chat_stream() 一次**，从流式增量同时解析文本和工具调用

## 2. 修复 A：日志左对齐 + [LOG] 前缀

```python
def _print_box(title: str, lines: list[str]) -> None:
    """左对齐打印日志块，[LOG] 前缀标记（任何终端宽度都清爽）。"""
    text_w = 76  # 内容宽度
    print("[LOG] ┌" + "─" * text_w + "┐")
    print(f"[LOG] │ {title.ljust(text_w - 1)}│")
    for line in lines:
        for sub in line.split("\n"):
            display = sub if len(sub) <= text_w - 1 else sub[: text_w - 2] + "…"
            print(f"[LOG] │ {display.ljust(text_w - 1)}│")
    print("[LOG] └" + "─" * text_w + "┘")
```

- 每行 `[LOG]` 前缀 → 一眼分辨日志 vs 输出（替代右对齐的视觉分区）
- 左对齐 → 任何终端宽度都不变形

## 3. 修复 C：流式单调用（核心）

### 3.1 llm.py：chat_stream 升级为"累积 + 回调"模式

```python
def chat_stream(self, messages, tools=None, on_delta=None) -> ChatResult:
    """流式调用：on_delta 回调逐块文本（打字机），返回累积完整 ChatResult。

    从流式增量同时解析：
    - delta.content → 文本（逐块回调 + 累积）
    - delta.tool_calls → 工具调用（累积 id/name/arguments 分片）
    返回标准 ChatResult（content 或 tool_calls），与 chat() 同构。
    """
    stream = self._client.chat.completions.create(..., stream=True)
    content_parts: list[str] = []
    acc: dict[int, dict] = {}  # tool_call index -> 累积

    for chunk in stream:
        delta = chunk.choices[0].delta
        if delta.content:
            content_parts.append(delta.content)
            if on_delta:
                on_delta(delta.content)
        if delta.tool_calls:
            for tc in delta.tool_calls:
                idx = tc.index
                acc.setdefault(idx, {"id": "", "name": "", "args": []})
                if tc.id: acc[idx]["id"] = tc.id
                if tc.function:
                    if tc.function.name: acc[idx]["name"] = tc.function.name
                    if tc.function.arguments: acc[idx]["args"].append(tc.function.arguments)

    if acc:
        tool_calls = [ToolCall(id=a["id"], name=a["name"],
                               arguments=json.loads("".join(a["args"]) or "{}"))
                      for _, a in sorted(acc.items())]
        assistant_message = {"role": "assistant", "content": None,
                             "tool_calls": [{"id": tc.id, "type": "function",
                                             "function": {"name": tc.name,
                                                          "arguments": json.dumps(tc.arguments, ensure_ascii=False)}}
                                            for tc in tool_calls]}
        return ChatResult(content=None, tool_calls=tool_calls, assistant_message=assistant_message)

    full = "".join(content_parts)
    return ChatResult(content=full, tool_calls=None,
                      assistant_message={"role": "assistant", "content": full})
```

**关键：返回标准 ChatResult** —— 与 chat() 同构，log_response 零改动，agent 分支逻辑统一。

### 3.2 agent.py：流式分支改为单调用

```python
def chat(self, user_input, stream_callback=None):
    ...
    for _ in range(self.max_turns):
        if stream_callback is not None:
            # 流式模式：一次调用（on_delta 打字机 + 累积完整结果）
            result = self.client.chat_stream(
                self.messages, tools=get_tool_schemas(), on_delta=stream_callback)
            if self.logger:
                self.logger.log_request(self.messages, get_tool_schemas())
                self.logger.log_response(result)
        else:
            # 普通模式：chat()（向后兼容，行为不变）
            result = self.client.chat(self.messages, tools=get_tool_schemas())
            if self.logger:
                self.logger.log_request(self.messages, get_tool_schemas())
                self.logger.log_response(result)

        if result.tool_calls:
            ...（执行工具，不变）
        else:
            self.messages.append(result.assistant_message)
            if self.logger: self.logger.log_final_answer(result.content or "")
            return result.content or ""
```

**效果：**
- 最终回答轮次：1 次 API 调用（原来 2 次）→ **省一半费**
- 日志 [RESP] = 实际输出（同一个 result）→ **日志不再骗人**
- 工具调用轮次：流式模式也能识别（解析 delta.tool_calls）
