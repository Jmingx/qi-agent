# TODO 管理（docs/todos/）

管理项目各模块的待办事项清单。**每个模块一个文件**，状态打勾、价值标注，避免想法遗漏。

## 约定

- 状态：`⬜ 未开始` / `🚧 进行中` / `✅ 已完成`
- 价值：`P0`（核心，强烈建议）/ `P1`（重要）/ `P2`（增强，锦上添花）
- 难度：⭐（简单）~ ⭐⭐⭐⭐⭐（复杂）
- 完成一个条目时：状态改 ✅ + 在"完成记录"里补 commit/tag 与日期
