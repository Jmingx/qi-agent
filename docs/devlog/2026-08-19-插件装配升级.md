## 遇到的问题与解决
1. **--stats 防重复安装**：如果配置已启用 tool_stats 且 --stats 也传，直接手动 install 会装两份（统计双倍）。解决：--stats 不是"再装一个"，而是**向配置注入** `{"tool_stats": {"enabled": True}}`——单一装配路径，天然防重
2. **tomllib 二进制读取**：tomllib.load 要求二进制模式打开文件（`open(path, "rb")`）——不是文本模式，第一次写容易踩
3. **测试隔离**：registry 测试的假插件注册后必须 _cleanup（pop），否则污染其他测试（沿用 test_registry.py 模式）
