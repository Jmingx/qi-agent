## 遇到的问题与解决
1. **拼接构造两次踩坑**：`('op' + 'en')('x', 'w')` 是**字符串不可调用**（TypeError）——
   不是函数！正确构造：`getattr(__builtins__, 'op' + 'en')`（v1 清单无 getattr、
   无 "open(" 子串 → 真实绕过）。教训：构造"绕过代码"要确保它真的能执行
2. **测试用了不存在的文件**：README.md 项目根**没有**（ls 验证）——read 测试的
   FileNotFoundError 是假象（文件本来就不存在），测试无效。改用真实存在的
   pyproject.toml。教训：**测试断言前先确认前提存在**
3. **write/read 测试不对称的困惑**：调试发现 read 在项目根也报 FileNotFoundError
   （README.md 不存在）——排查后修正，非实现问题
