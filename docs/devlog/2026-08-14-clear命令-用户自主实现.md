# 2026-08-14 用户自主实现：clear 命令（清理上下文）

## 做了什么
- 用户独立实现了 `clear` 命令：清理对话上下文，保留 system prompt
- 功能：CLI 输入 `clear` → agent.clear_context() → 历史重置为仅 system prompt
- 经过 3 轮评审迭代：初版 → 修 bug → 规范化
- 补充 3 个回归测试锁死行为

## 怎么做的（协作过程）
1. **用户初版**：添加 clear_context() + cli 命令处理，手动验证 OK
2. **评审发现 bug**：clear_context 硬编码 DEFAULT_SYSTEM_PROMPT，会覆盖自定义 system_prompt（阶段4配置化后必现）
3. **用户修复**：__init__ 记住 self.system_prompt，抽 _reset_messages() 复用
4. **第二轮评审**：__init__ 未复用 _reset_messages、冗余类型注解、命名单复数
5. **用户终版**：全部采纳，__init__ 复用 + 删冗余注解 + _reset_messages 复数
6. **补测试**：test_clear_context.py 3 个用例（重置/保留自定义prompt/清理后继续对话）
7. 验收：36 passed + ruff 通过 + 真实 CLI 对话验证 clear 生效

## 遇到的问题与解决
1. **system_prompt 覆盖 bug**：clear 用 DEFAULT 重置，自定义 prompt 丢失。解决：Agent 记住 self.system_prompt，重置用它
2. **重复代码**：__init__ 和 _reset_messages 两处构造初始消息。解决：__init__ 调用 _reset_messages
3. **赋值顺序**：self.system_prompt 必须在 _reset_messages() 之前赋值（方法依赖它）
