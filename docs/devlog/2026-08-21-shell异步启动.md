# 2026-08-21 shell 异步启动（background 参数）

## 需求

常驻进程（游戏/服务器）启动应**立即返回**，不阻塞对话——超时杀是"事后补救"，
异步启动是"事前正确"。（承接同日 shell 超时死锁修复，见
2026-08-21-shell超时死锁修复.md）

## 方案（docs/plans/2026-08-21-shell异步启动方案.md，决策点 1-4 批准）

`shell(command, background=True)`——对齐 Hermes terminal 工具 background 参数：

- **不等待**：Popen 后直接返回 `[已启动] PID xxx`
- **断管道**：stdout/stderr → DEVNULL（防 64KB 缓冲写满阻塞子进程）
- **detach**（Windows）：DETACHED_PROCESS | CREATE_NEW_PROCESS_GROUP——
  完全脱离控制台，agent 退出程序照跑
- 安全链不变：白名单/审批先行，background 只是执行方式

## 验证

- 工具实测 0.006s 返回 + PID 进程存活
- schema 检查 `['command', 'background']` 暴露、approved 隐藏
- 全量 **247 测试全绿 + ruff 零错误**
