## 遇到的问题与解决
1. **round 银行家舍入**：`round(6.25, 1) = 6.2`（不是 6.3）——测试断言修正为 -6.2 并注明语义
2. **wait_for 超时不能终止线程**（重要，未完全解决）：e1 任务 60s 超时后，
   线程池里的 LLM 调用**仍在执行**（线程无法强杀）→ asyncio.run 结束 join 卡 300s
   （RuntimeWarning: executor did not finish joining its threads）。
   **根治方案**：LLMClient 加请求超时（openai SDK timeout，如 60s）——任何 LLM
   调用最迟 60s 返回，线程自然结束。**已记 TODO（LLM 调用超时，联动"命令执行超时"）**
3. **e1 真实超时**：模型在"读不存在文件"上多轮尝试（>60s）——超时本身是有效信号
   （错误恢复挣扎），保留；可考虑 error 类任务放宽超时（后续调优）
