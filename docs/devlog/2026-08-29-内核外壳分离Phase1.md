# devlog: 内核/外壳分离（Phase 1——Gateway + JSON-RPC）

日期：2026-08-29
方案：docs/plans/2026-08-28-内核外壳分离方案.md（评审通过）

## 做了什么（Phase 1：进程内解耦）

1. **gateway/ 包**（qi_agent/gateway/——新层）：
   - protocol.py：JSON-RPC 2.0 消息模型（请求/响应/通知）+ dispatch
     + RpcError（带错误码异常——handler 抛 → dispatch 保留码）
     + 错误码（-32700~-32603 标准 + -32001 会话不存在/-32002 并发）
   - gateway.py：Gateway 类——方法集（session/create、session/resume、
     message/send、approval/respond、session/stop）+ 事件回调桥
     + 审批请求-响应（approval_id + 暂停等待 + 超时拒绝 fail-closed）

2. **CLI 重写为外壳**（cli.py 356 → ~280 行）：
   - CliShell 类——只调 Gateway 方法，不 import 内核组件
   - 命令处理（/status /resume /remember /new /stop clear）→ Gateway
   - 审批弹窗（外壳唯一读 stdin 的交互点——stdin 竞争根治）
   - 通知渲染（delta 流式 / approval 弹窗）

3. **测试**：
   - test_gateway_protocol.py（6：消息解析/响应/错误码）
   - test_gateway.py（5：会话/审批桥/超时拒绝/流式通知）
   - test_cli_shell.py（8：外壳命令/审批弹窗）
   - 删除 4 个过时 CLI 测试（验证旧 build_runtime 行为——新外壳
     由 test_cli_shell 覆盖）

## 遇到的问题与解决

| 问题 | 解决 |
|---|---|
| dispatch 自定义错误码丢失（-32603） | RpcError 异常类（带 code）——handler 抛 → dispatch 保留 |
| RpcNotification 无 to_json | 补通知序列化方法 |
| CLI 测试 mock 旧 build_runtime | 批量适配 Gateway mock + 删除过时测试 + test_cli_shell 重写 |
| F841/F821/E501 | 未用变量/缺 import/行长——修复 |
