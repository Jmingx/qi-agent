## 遇到的问题与解决
1. **测试断言设计失误**：test_user_message_appended 原断言"chat 后历史最后是 user"，实际应为 assistant（一轮以模型回复结束）。修正为断言 user 在 history[1]。
2. **PYTHONPATH 环境污染**：Hermes 终端注入 PYTHONPATH 指向 Hermes venv，导致 uv run python 导入损坏的 openai/pydantic_core。解决：命令加 `PYTHONPATH=` 前缀。已存入长期记忆。
3. **API key 配置**：git-bash 会话中 setx 不立即生效，但项目走 .env 读取（python-dotenv），不受影响。
