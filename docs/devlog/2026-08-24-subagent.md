# 开发记录：Subagent（agent-as-tool + 半双工协议 + 受限子集 + 授权）

日期：2026-08-24（方案 2026-08-23 跨天实施）

## 做了什么

subagent 五阶段全部落地（TDD）：

- **Phase 1 受限子集**：Agent.tools 白名单 + get_tool_schemas(allowlist)
  过滤（层 1）+ executor 执行前硬校验（层 2，SEC_BLOCK_NOT_ALLOWED）
- **Phase 2 delegate_task 工具**：嵌套 Agent + 结构化 result（JSON）+ 授权清单
  （write_paths 前缀匹配，子 agent 不弹窗 fail-closed）
- **Phase 3 半双工协议**：SubagentManager + SubagentContext 生命周期状态机
  （v0.4.27 改名：原 SubagentSession → SubagentContext——任务运行环境，
  与未来 agent session（对话持久化）职责分离，见 subagent.py 头注释）
  （running/completed/failed/stopped）+ steer（pre-step 瀑布钩子注入）+
  stop（标志位）+ poll（探活）+ partial 回报
- **Phase 4 CLI /delegate**：手动入口（用户主导）+ 审计事件（subagent/* 命名空间）
- **Phase 5 评测**：d1/d2 真实 LLM 任务（主 agent 主动委派）+ 递归禁止
  结构测试（子集永远无 delegate_task）

## 遇到的问题与解决

1. **d1/d2 首跑 0/2——delegate_task 根本没注册**
   builtin/__init__.py 漏 import → 工具静默不存在 → 主 agent 自己干活
   → 补 import + 条件审批（纯只读委派放行，带 write_paths 才弹窗）
2. **循环导入**：delegate_task.py 模块级 import Agent → 工具包初始化死锁
   → Agent 延迟到 _run_subagent 内 import
3. **生产系统提示词太简陋** → 模型不用 delegate_task
   → agent_factory 用 PROD_SYSTEM_PROMPT（工具使用策略：何时委派）
