## 遇到的问题与解决
1. **模块命名冲突+循环导入**：tools.py 和 tools/ 包同名。解决：注册机制移入 tools/registry.py
2. **API 报 400 invalid type: map**：回填 assistant_message 时 arguments 用了 dict，协议要求 JSON 字符串。解决：json.dumps 还原
3. **PYTHONPATH 污染影响 pytest**：导入链经过 openai 后 pytest 也中招。解决：PYTHONPATH= 前缀
4. **旧测试 FakeClient 不兼容**：agent 期望 ChatResult，旧测试返回 str。解决：更新 FakeClient
