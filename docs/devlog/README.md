# 开发记录（docs/devlog/）

按 AGENTS.md P1-3 要求，每次开发会话/任务完成后追加记录。

## 命名规范
- `YYYY-MM-DD-<内容摘要>.md`

## 记录模板

```markdown
# YYYY-MM-DD <内容摘要>

## 做了什么
（本次会话完成的功能/任务）

## 怎么做的
（关键实现路径、文件、决策）

## 遇到的问题与解决
（坑、报错、解决过程）

## 下一步
（下次要做什么）
```
