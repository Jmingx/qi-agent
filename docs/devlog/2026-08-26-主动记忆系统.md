## 做了什么（V1：规则触发 + 间隔提炼 + subagent 异步）

1. **context 提炼触发**（context.py）：
   - memory_extract_interval = 10（提炼间隔——用户拍板）
   - last_extract_turn（上次提炼轮数——防重复触发）

2. **规则触发自动记忆**（memory 插件）：
   - post-llm 监听（从 messages 最后一条 user 提取输入）
   - 用户偏好模式（我喜欢/我习惯/请记住/我的爱好）→ USER.md
   - 项目决策模式（我们决定/我们约定/以后用）→ MEMORY.md
   - 无需审批（用户明说"记住"= 授权——方案 D3）
   - 失败容错（写失败不影响对话）

3. **间隔提炼 subagent**（agent_manager._maybe_extract_memory）：
   - turn 达到 10 轮 → 触发提炼
   - 提炼 = 后台 daemon 线程（复用 spawn 执行链——不新造引擎）：
     读最近 20 条消息 → LLM 分析 → [USER]/[MEMORY] 行 → 写记忆文件
   - 主对话不阻塞（异步）；失败容错（结果丢弃）

## 遇到的问题与解决

| 问题 | 解决 |
|---|---|
| post-llm payload 无 user_input | 从 messages 最后一条 user 提取 |
| mock 内部方法不存在（提炼内联） | 测试改验证行为（起线程 + last_extract_turn 更新） |
