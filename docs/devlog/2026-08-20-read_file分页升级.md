# 2026-08-20 read_file 分页升级（v0.4.20）

## 做了什么
- read_file 从"固定 2000 字符截断"升级为**行级分页读取**：
  - `read_file(path, offset=1, limit=2000)`——offset/limit 分页参数
  - 返回 header 元信息（"第 X-Y 行（共 N 行）"）——模型知道文件大小
  - 未读完时 tail 续读提示（"剩余 M 行，可用 offset=N 继续读取"）——可行动设计
  - 字符上限 50_000 双保险（2000 行超大文件防撑爆上下文）
  - 手写 schema（offset/limit 有默认值非必填）
- 9 个新测试（220 passed）
