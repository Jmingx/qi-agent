## 遇到的问题与解决（API 实况 vs 方案预期，坑多，值得记录）
1. **print 机制变了**：8.5 把 print(x) 改写为 `_print._call_print(x)`（模块开头注入 `_print = _print_(_getattr_)`），Zope 原版 PrintCollector 是"收集文本供宿主读"——CLI 场景直接自定义 _StdoutPrint 输出 stdout
2. **_getiter_/_inplacevar_ 守卫缺失**：for 循环 → `_getiter_(it)`；`n += 1` → `n = _inplacevar_("+=", n, 1)`（属性/下标原地运算被禁，名字原地运算走守卫）——逐个补守卫
3. **import 不改写**：8.5 的 import 语句保留 IMPORT_NAME 字节码——默认拦截靠"受限 builtins 无 __import__"（ImportError: __import__ not found），**不是方案预期的 _import_ 守卫**。放行机制改为注入受限 __import__ 白名单守卫（方案偏差，devlog 记录）
4. **沙箱配置被 env 白名单过滤**：QI_SANDBOX_EXTRA_MODULES 被子进程的 _build_safe_env 丢弃（不在白名单）→ runner 读不到。修复：_build_safe_env 透传 QI_SANDBOX_* 前缀（沙箱配置，非密钥）
5. **globals() 取不到内建**：`globals().get('round')` 返回 None（内建不在模块 globals）→ 改用 `getattr(builtins, name)`
6. **safe_builtins 已含 _getattr_**（Guards.py:281 注入 safer_getattr），显式提供 default_guarded_getattr 覆盖也无妨
