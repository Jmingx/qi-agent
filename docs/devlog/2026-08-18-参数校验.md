# 2026-08-18 工具参数校验（v0.4.7）

## 做了什么
- registry.py 新增 `validate_arguments(schema, arguments)`：执行前校验，三检查
  - 必填检查：缺参数 → "缺少必填参数: path"
  - 类型检查：类型不符 → "期望 string, 实际 int"（含 bool 严格化：integer 拒绝 bool）
  - 多余参数：未声明参数 → "未知参数: mode（可用参数: path）"
- `execute_tool` 接入：校验失败返回 `[参数错误]` 前缀（区分"传参错了可修正" vs "工具失败换工具"）
- 11 个测试（tests/test_validate.py）
