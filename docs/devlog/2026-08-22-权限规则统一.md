## 方案（用户评审拍板：选项 C + path_security 收敛）

**规则单一来源 + 分层检测保留 + 安全域独立子包**：

```
qi_agent/security/          ← 新子包（安全域收敛，中立：tools/plugins 都 import）
├── __init__.py
├── rules.py                ← 命令权限规则唯一来源（红线/组合语法/审批/代码执行）
└── path_security.py        ← 从 tools/ 迁入（8.3 短名检测等）
```

- shell.py / security_guard.py 删除各自规则定义 → `from qi_agent.security.rules import ...`
- **检测逻辑不动**：shell 工具层兜底（插件可关时的安全底线）+ security_guard
  判档（白名单/审批/红线/代码执行）职责不变，只是数据同源
- **死代码消除**：APPROVAL_PREFIXES 里的 python/py/npm/pip/npx 被
  CODE_EXEC_PREFIXES 先判定（永不命中）——共享后显式不重复（专项测试锁定）
- `_RESTRICTED_MODULES`（run_python 降级判据）保留在 security_guard：
  沙箱内容策略（模块白名单）与命令权限规则正交（决策点 2）
