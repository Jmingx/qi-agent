1. **批量替换误伤机制引用**：`from qi_agent.plugins import load_plugins` 被脚本
   误改成 builtin 路径（load_plugins 是机制名）——手动修复 3 处
   （tools/__init__、plugins/__init__、agent_factory.py）
2. **write_file 项目根推导失效**（重要）：`_PROJECT_ROOT` 用 `__file__.parent×3`
   推导，移动进 builtin/ 后多一层目录 → 项目根变成 qi_agent/ → 相对路径写文件
   误判"项目外"触发审批。修复：parent×4 + 注释说明
3. **ruff 残留**：verify_executor.py 未用 import（ToolDecision）、
   test_tool_executor.py 未用变量（answers）——清理
