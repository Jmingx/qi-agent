# 技术形态决策矩阵

按顺序命中即选，选择后把理由写进交付说明。

| 触发条件 | 形态 | 产出 |
|---|---|---|
| 无图形显示需求 / 快速原型 / 教学演示 / 无法澄清 | CLI 文本游戏（纯 Python 标准库） | 单个 `.py` |
| 用户明确要图形窗口、动画、手柄操作 | pygame 桌面游戏 | `main.py` + `requirements.txt` |
| 用户要在浏览器里玩、分享链接给他人 | HTML5 + 原生 JS（无构建步骤） | 单个 `.html` |

## 默认假设（无法与用户交互时使用）
- 语言：Python；界面：中文；单人；键盘操作；单局 1~5 分钟；无音效；无网络；无第三方依赖。
- 目录：项目下 `games/<游戏名>/`，单文件直接放该目录。
- 在交付说明中列出以上假设，用户可要求调整。
